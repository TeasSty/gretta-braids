# Design concept — GRETTA BRAIDS

## Client / project

- Name: GRETTA BRAIDS | Афрокосы Афрокудри | Бузулук
- Date: 2026-11-23
- Niche: локальная студия афроплетения (афрокосы, афрокудри, брейды) в Бузулуке
- Concept-ID: `2026-11-23-gretta-rows-horizontal-v1`
- Composition-archetype: `horizontal-scroll-gallery`
- Forbidden-for-this-niche: quiet-luxury black/cream/gold; cream `#F4F1EA` + terracotta + serif; purple/indigo UI-gradients; hero + 3 equal feature cards; lead-gen skeleton hero→services→prices→form as «composition»; клон Anok cream/serif folio или Etnia black/gold; занятые жесты Desktop (filmstrip-process, product-theater, diagonal-technical, passport-kraft)
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: референс в телефоне → разбор пробора → 3–8 часов в кресле → фото «после» → уход и срок носки
- Материалы: каникалон, трессы, бусины/каффы, клипсы, сатиновая шапочка
- Место/свет: компактная студия, жёсткий свет на проборы и фактуру, кадры как в сторис
- Жаргон: knotless / брейды / афрокудри / каркас·точка / вес / срок носки
- Сенсорика: ритм пальцев, ровные ряды, вес готовой причёски
- Характер бренда: руками, без ИИ-глянца; «кайфую от того, чем занимаюсь»; локальный boutique, не megacorp

## Unique thesis

1. Mood: тактильный craft студии — проборы, ряды, вес каникалона; не «luxury salon».
2. Type rationale: Oswald (сжатый display = натяжение ряда пробора) + Onest (кириллица, живой UI). Не Inter/Roboto; не Alumni/Barlow/Big Shoulders с прошлых проектов.
3. Palette logic (from materials/light): espresso волос `#1A1412`; студийная штукатурка `#D8D0C6`; каникалон-lilac `#6B4E8C` только как материалный акцент (не UI-gradient); медь бусин `#A66B4A`; текст `#2A2420`.
4. Composition: horizontal-scroll-gallery — горизонтальные «ряды» фактур как главный жест; hero = full-bleed текстура без карточек.
5. Motion: медленный horizontal drag ленты + лёгкий reveal пробора; 2–3 жеста.
6. Main gesture: линия пробора / ряд как сетка сайта. Secondary: нумерованные кадры работ; медный CTA.

## Anti-clone checklist

- [x] Carryover: не reuse Avtosvet diagonal / Sandra product-theater / SНОВА filmstrip / passport-kraft; другие шрифты и палитра
- [x] Benchmark clone: Anok = планка фото/ритма/архива, не cream+serif; Etnia = full-bleed + brand presence, не black/gold
- [x] AI clusters: не purple-gradient UI; не cream+#F4F1EA+terracotta+serif; не broadsheet; не hero+3 cards; не quiet-luxury default
- [x] Brand test: без лого всё ещё читается как афроплетение (ряды, проборы, каникалон) — PASS

## Palette + type

- Palette (aligned to VK logo + real work):
  - `--hair` `#121212` — mono лого / уголь
  - `--plaster` `#DEDCD8` — пепел студии (не cream-cluster)
  - `--lilac` `#7A6A9A` — волокна обложки VK
  - `--copper` `#C45F2C` — медный каникалон из реальных работ
  - `--ink` `#1C1C1C` · `--foam` `#F2F0EC`
- Type: Oswald (как caps в лого) + Marck Script («афроплетение») + Onest
- Brand mark: логотип VK (корона / силуэт) в header и hero
